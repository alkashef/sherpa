Philosophy

Intent
The human owns the spec and each release. No session changes the spec.
Method
The AI writes the design, the plan, the tests and the code.
Proof
A result counts only when a deterministic check confirms it.
Independence
No session checks its own work. One session writes the tests, one writes the code, and one reviews it.
Autonomy
The human approves before a run and reviews after it. During a run, the AI works alone. It stops only for a named blocker or a human test.
Cost
Proof comes before token cost.
Scope
sherpa is for Claude Code only.
