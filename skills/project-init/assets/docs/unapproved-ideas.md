# Unapproved ideas

Ideas for later that nobody approved. An idea is not a requirement and not a design decision: never
design, plan, test or build from this file (`docs/workflow.md`, Rules).

- To note an idea, add one line to the list. Use the user's words and do not act on it.
- To take an idea up, run `/sherpa` and name it. `/sherpa` routes it to `/write-spec` (new or
  changed behavior), `/write-design` (a change of design with no change of behavior) or
  `/write-plan` (a fix of behavior the spec already states).
- The skill that takes an idea up deletes its line, and so does the user who drops one. Git history
  keeps it.
