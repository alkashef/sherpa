    Ahmad Alkashef · October 2026

    Demo steps

    1. Init project

      1. Follow the instructions in https://github.com/alkashef/sherpa to set up the SDD skills on your machine.

      2. Create a new folder on your local machine called sdd-demo.

        1. Open VS Code

        2. Open sdd-demo in it

        1. Open Claude Code inside VS Code

        2. Set Sonnet 5.5 / high

        3. Set bypass permissions

      5. Run the /project-init skill.

      6. Answer the skill questions.

        1. sdd-demo
        2. CV matcher
        3. All except a CLI, static-site, MCP, Docker.
        4. public

      7. After sdd-demo is set up, follow the steps in the Claude Code window.

        1. Open GitHub

        2. You should find the project repo and its files checked in

    2. Develop specs

        1. Start a new Claude Code session

        2. Run the /write-spec skill

      2. Answer the interview questions:

        • Users: hiring manager, a recruiter
        • Last time: yes, they did it by hand, and it took them a long time. They had to read all the CVs and find the suitable ones for each job description.
        • Where it went wrong: the recruiter tries to match by keyword (e.g., Python, Java, etc.) without enough technical understanding of the job, and they miss critical information that the hiring manager could see as a red flag: very short tenures in previous jobs.

        1. Review edits to the spec.md

        2. Iterate

      4. A shortcut

        1. Copy a finished spec.md

        2. Tell Claude you did so:

          I manually developed all the specs and saved them into spec.md. Consider them approved.

    3. Design your app

        1. Open a new Claude Code session

        2. Run /write-design

      2. Answer the interview questions:

        I have an OpenAI API. You can send CV and JD text to OpenAI.

      3. A shortcut

        1. Copy a finished design.md

        2. Copy the CV and JD data into the data folder

        3. Tell Claude you did so:

          I developed the full design in design.md and added the CV and JD data in the data folder.

    4. Design your UI

      1. Do the UI design:

        /design given spec.md and design.md, develop a UI design for this app. Use fresh, vibrant colors and minimal design.

      2. Apply changes to the UI in the browser.

        1. Return to VS Code

        2. Tell Claude you approved the UI design:

          UI design approved, and save the UI design to docs\frontend\ to be used in the build.

    5. Plan your build

        1. Open a new session

        2. Run the /write-plan skill

        1. Review the plan

        2. Approve the plan

    6. Build your app

      1. Run the milestones runner:

        python scripts\milestones-runner.py

      2. If the milestone runner blocked a milestone:

        1. Paste its log to Claude AI to solve it for you

        2. Approve the milestone in plan.md

        3. Commit

        4. Run the milestone runner again
