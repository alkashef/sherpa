`★ Insight ─────────────────────────────────────`
- The e2e tests remove `LEDGER_DATA` from the environment before each run and set it to a file in a temporary folder. The default-path test runs with that folder as the working directory, so no test touches the real `data/ledger.json`.
- The amount and the stored entry are checked against exact texts from `docs/spec.md` and the data model in `docs/design.md`, such as `"12.50"` and `amount_cents: 1250`. They are never worked out the way the code would, so a rounding bug in the code cannot hide.
